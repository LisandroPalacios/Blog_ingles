05 / TECHNICAL BROCHURE

ELECTRONIC COMPONENTS

For this assignment, we had to present a brochure about our training program.

TRANSISTORS

A semiconductor device that uses a small input signal to control a larger current.

Main function

Electronic switching and signal amplification.

Applications

Audio amplifiers and digital logic circuits.

MOSFETs

A field-effect transistor whose conductive channel is controlled by an electric field at its gate.

Main function

Voltage-controlled switching with low gate current.

Applications

Motor drivers and switch-mode power supplies.

CAPACITORS

Passive components that store energy in an electric field between conductive plates.

Main function

Charge storage, filtering, and voltage smoothing.

Applications

Power-supply decoupling and signal filters.

LED DIODES

A light-emitting diode converts electrical energy into light when it is forward biased.

Main function

Emit light as current flows in the forward direction.

Applications

Status indicators and lighting systems.

INDUCTORS / COILS

Conductors wound into a coil that store energy in a magnetic field when current flows.

Main function

Oppose rapid current changes and store magnetic energy.

Applications

Filters and DC-DC power converters.

MICROPROCESSORS

Programmable integrated circuits that execute instructions and process digital data.

Main function

Perform calculations and coordinate computer operations.

Applications

Computers, embedded systems, and control devices.
